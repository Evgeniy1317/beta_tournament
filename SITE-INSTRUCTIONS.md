## 🔄 Обновления

### Как обновить контент:
1. **Зайдите** в панель управления Hostinger
2. **Откройте** File Manager
3. **Найдите** нужный HTML файл
4. **Отредактируйте** содержимое
5. **Сохраните** изменения

### Google Forms и Sheets:
- **Форма регистрации** автоматически обновляется
- **Список игроков** обновляется каждые 30 секунд
- **Данные** сохраняются в Google Sheets
