# THE KING OF SPADES Tournament Website

A professional tournament website for the 3rd Annual Spades Tournament & Birthday BBQ celebration.

## 🎯 Features

- **Responsive Design** - Works perfectly on desktop, tablet, and mobile
- **Google Forms Integration** - Live player registration
- **Real-time Player List** - Automatically updates from Google Sheets
- **Professional Design** - Clean, modern interface
- **Tournament Rules** - Complete game rules and regulations
- **Payment Integration** - Multiple payment methods support
