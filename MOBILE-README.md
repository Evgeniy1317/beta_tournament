# Mobile Version - THE KING OF SPADES Tournament

## 📱 Mobile-First Responsive Design

This directory contains mobile-optimized versions of the tournament website, designed specifically for mobile devices without affecting the desktop version.

## 📁 Mobile Files Structure

### HTML Files
- `mobile-index.html` - Mobile homepage
- `mobile-players.html` - Mobile players page
- `mobile-rules.html` - Mobile rules page
- `mobile-register.html` - Mobile registration page

### CSS Files
- `css/mobile-style.css` - Mobile-specific styles (only mobile breakpoints)

### JavaScript Files
- `js/mobile.js` - Mobile-specific functionality
